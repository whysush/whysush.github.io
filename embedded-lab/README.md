# Embedded Lab Bench

Reference site for the IIT Patna EE embedded systems lab: pick an experiment to see its connections, setup steps, code (short and lab versions) and viva questions.

| No. | Experiment |
|---|---|
| 1 | IIR filter (Arduino Uno) |
| 2 | FIR filter (Arduino Uno) |
| 3 | STM32 LED blinking (Nucleo-F401RE) |
| 4 | STM32 LED with push button (Nucleo-F401RE) |
| 5 | ADC with potentiometer (Nucleo-F401RE) |
| 6 | UART between two Arduinos |
| 7 | SPI & I2C between two Arduinos |
| 8 | FPGA full adder (Artix-7, Vivado) |

Single self-contained `index.html`, no build step. Served by GitHub Pages from the `main` branch root.

Direct links: `#e3-code`, `#e7-i2c-viva`, `#reference`, etc.
